# LongMemEval 时序题检索深度与回答上下文配对诊断（2026-10-25）

目的：检查 Top-5 本地回答器的时序错误是否仅因可读证据条数或上下文长度不足。固定第四版纯词法 Search、LongMemEval `s_cleaned` development 最前 5 道 `temporal-reasoning`、`qwen3-vl:4b-instruct`、原提示、温度 0 与 seed 0；仅改变 Top-K 和 `num_ctx`。没有修改生产服务、官方评测或冻结 holdout。报告在忽略版本控制的 `data/longmemeval-temporal-top{5,20}-ctx{8,16}k-5.json`；Top-5/8K 使用既有 30 题报告中的同 5 题。这个回答器和严格字面评分都不是官方 Answer/Judge。

| Top-K / `num_ctx` | 严格字面正确 | 逐题观察 |
| --- | ---: | --- |
| 5 / 8192 | 0/5 | 基线；两题缺必要会话，三题已有会话仍答错。 |

结论：Top-20 加 16K 在一个小样本上出现了事实等价回答，但没有稳定的答案级净提升证据；Top-20/8K 还增加了具体错误与臆造日期。增加检索深度或本地上下文不是可直接部署的第五版 Search 候选，也不能用这 5 题推断官方 C 类分数。下一步若继续研究时序题，须检查**具体事实消息**是否进入真实 Search Top-100，以及模型实际可见的片段边界，再在更大的公开答案集做固定口径配对评测。

## Top-100 事实片段复核

按第四版纯词法 Search 重新写入同五题公开历史，并只在检索**之后**用公开证据来源 ID 定位事实句。MoMA 参观的用户原话在第 8 条、Met 展览在第 2 条；三事件排序的三句用户事实在第 1–3 条；吊灯事实在第 1 条；连续两场慈善活动分别在第 63、91 条；键盘与蓝草在第 1/2、5 条。故五题的必要事实都进入 Top-100，但 MoMA 和慈善题没有在 Top-5 齐全。这里的 Top-100 是来源可见性，不保证官方回答器使用全部结果。

另一个更关键的代理缺陷：公开规范化样本保留 `query_time`，例如吊灯题为 2023-04-01 08:09，而当前 `run_longmemeval_local_answerer.py` 的 `ask()` 只传问题和检索片段，**未传查询时间**。因此“几周前/几个月前”题可能缺计算基准；它的错误不能直接算作 Search 失败。此前给三题额外时间提示的试验仍为 0/3，说明单补日期也没有修复该小模型，但这个本地代理不足以判断官方 C 类能力。未来若重建时序答案级代理，应预先固定查询时间传递规则，再做同题基线与候选配对。
