# 第五次 Smoke 候选：显式环境变更后的阶段优先

## 改动

Search 在同一用户历史中找到短的、用户发出的显式环境变更通知时，对原排序前 `max(top_k, 100)` 条候选做稳定分组：通知之后写入的证据先返回，组内保留原相关性顺序。历史查询维持原排序；没有此类通知的历史维持原排序。识别条件为英文 `NOTICE`/`IMPORTANT`/`UPDATE` 等前缀、变更词和环境对象词同时出现，不包含基准题号、表名或答案。数据格式与 API 不变，第四版可读取新写入数据。

## 发布判断

这是针对公开环境变更轨迹的通用检索改动，证据覆盖提升明显且普通公开历史没有触发。**54/85 是检索代理，不是答案正确率或官方 G4 分数。**现有本地 CLBench 回答器在原生四题上 0/4，无法辨别答案收益；第五次官方 Smoke 将承担答案级检验。先取得精确提交 CI、Linux 16/16 容量及 Railway 部署身份，再对绑定的新版本运行第五次 Smoke。Smoke 后按实际分项与第四版配对决定保留或回退；不要用这个代理承诺一定涨分。
