- 技术基础：零基础，由 Codex 负责实现与说明
- 预算：约 100 元
- 代码托管：已有 GitHub 账号

## 官方接口硬约束

- Add 是同步接口；必须在消息已存储且可搜索后才能返回 HTTP 200。
- Add 必须原样回传 `request_id`、`user_id` 和 `session_id`。
- Search 只返回相关记忆，不生成最终答案。
- Search 的结果必须按相关度从高到低排列。
- 所有检索必须以 `user_id` 隔离。
- 评测数据不得用于训练、分析或传播，并应在评测结束 30 天内删除。
